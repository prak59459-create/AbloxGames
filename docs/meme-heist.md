# Meme Heist（4番）の作りなおし（2026年10月）

もとにしたのは Roblox の **Steal a Brainrot**（このドキュメントの中でだけ名前を書きます）。
オーナーが送ってくれた くわしいリサーチ（ゲームのしくみ・お金の流れ・キャラ・イベント）を
そのまま設計図にして、Ablox で動く オリジナル版を作りました。ゲームの中の 名前・キャラ・
イベント名は すべてオリジナルです（本物のキャラ名・ゲーム名は 使っていません）。

## 大きさ

| | 数 |
|---|---|
| ミーム（キャラ） | 300体（手作り 60体 ＋ どうぶつ49 × もの60 から 240体） |
| めずらしさ | 8（コモン・レア・エピック・レジェンダリー・ミシック・ミーム・ゴッド・シークレット・OG） |
| 変異 | 10（ゴールド ×1.25・ダイヤ ×1.5・ブラッド ×2・セレスティアル ×4・キャンディ ×4・ウィッチ ×4.5・ようがん ×6・ギャラクシー ×7・レインボー ×10・クリスタル ×13） |
| 特性 | 33（雨 +2.5・雪 +3・流れ星 +4・かみなり +6・UFO +8・いんよう +7.5 …） |
| イベント | 50（天気25・変異のあらし9・管理人7・きせつ7・とくべつ2） |
| ギア | 12 |
| 転生 | 15回 |
| 儀式 | 8 |
| スクリプト | 19ファイル・約5200行 |

## しくみ（もとのゲームと同じところ）

- **きち**: 8つ。カーペットの北と南に 4つずつ。3かいだて（1かいは さいしょから、2かいは 転生2、3がいは 転生10）。
  1かいに 台10。台のミームは 1秒ごとに お金をうみ、台の前の 緑のプレートに たまる（ふむと受けとる。金色のパッドで ぜんぶ）。
- **ロック**: 赤いパッド。60秒（転生1回ごとに +5秒）レーザーが出て、ほかの人は 入れない。来たばかりの 30秒も ロック。
- **カーペット**: 西の「ミームの門」から 2.4秒ごとに 1体。めずらしいほど 出にくい（コモン 600 : レア 250 : … : シークレット 0.35）。
  5分ごとに レジェンダリー以上、15分ごとに ミシック以上が かならず出る。買うと 自分のきちまで 歩いていく。
- **ぬすむ**: ロックしていない きちの台で「ぬすむ」→ 頭の上に もちあげて 自分のきちへ（60秒・おそくなる・ジャンプも ひくい）。
  もちぬしに タッチされる／たたかれる／ガードに つかまる／時間切れ → ミームは もとの台へ 歩いてもどる。
- **ばいりつ**: 1体のもうけ = キャラのもうけ ×（変異のばいりつ ＋ 特性のばいりつの合計）。
  例: ようがん（6）＋ ばくだん（4）＝ ×10。さらに 転生（1 + 0.5×回数）・図鑑ボーナス（10体ごとに +1%）・イベント（もうけ2ばい）。
- **合体マシン**: 同じめずらしさ 3体 → 1つ上の 1体（30秒〜10分）。中のミームは ぬすまれない。いちばん強い変異を 50% うけつぐ。
- **転生**: お金 ＋ きまったミーム（1〜10回目は 名前つき、11回目からは そのめずらしさ なら どれでも 2体）。
  お金と きちのミームは なくなり、ギア・図鑑・ラッキーブロックは のこる。
- **ラッキーブロック**: 6しゅるい（レア〜シークレット）。中身の かくりつは お店に 書いてある。買ったら 下のバーで 開ける。
- **儀式**: きまったミームを 2〜4体 そろえると 形（一列・三角・十字・四角・かさなり・なかよし・グリッチの四すみ・はさみ）に ならび、
  儀式でしか 生まれない ミームと とくべつなイベントが 来る。ミームは なくならない。庭にいる 友だちの ミームも かぞえる。
- **管理人**: マエストロ・ポッポ（オリジナル）。10分ごと（土曜日は 6〜7分ごと）に ステージで イベントを起こす。
- **きせつ**: today()（ホストのiPadの日にち）で。火曜日 タコス、日曜日 つり大会、10月 ハロウィン、12月 クリスマス、
  1月 お正月、2月 バレンタイン、夏まつり。きせつの あいだは マップに さがしものが出る。
- **ライバルのきち**: プレイヤーのいない きちには ライバル（オリジナルの8人）が住み、ミームを ならべて 見はっている。
  ぬすみの れんしゅうに なる。ときどき 🦹 どろぼうNPC が プレイヤーのきちを ねらう。
- **図鑑**: 300体・変異10・イベント50。10・25・50…体で ごほうび。
- **ミーム博物館**: スポーンのそばに めずらしいミームが かざってある（見るだけ。2分ごとに 入れかわる）。
- **るすのあいだの もうけ**: 最後に遊んだときから（3時間まで）の 20%。

## 子ども向けに かえたところ

- ライバルのガードは はこんでいる人より 少し おそい（にげきれる）。どろぼうNPCは タッチ1回で おいはらえる。
- めずらしいミームを 売るときは 2回おす。転生も 2回おす（なくなるものを 先に 見せる）。
- 🧭 ワープボタン（はこんでいる時は つかえない）。
- 儀式は 1人でもできる（もとのゲームは 何人も いる）。

## エンジンの こと（Ablox 2.4）

1体のミームは 根っこのブロック1つ ＋ 17こくらいの パーツ（parent でぶら下がる）。
ブロックを 作るたびに ホストの「ブロックのさくいん」が ぜんぶの ブロックを くらべなおしていて、
1体作るのに 15ミリ秒も かかっていました。Ablox 2.4 で さくいんの 更新を 作りなおし（くらべるのは
さくいんに いる所だけ・世界の ブロックを コピーしない・ぶら下がったパーツは いっしょに 動かす）、
1体 約3ミリ秒、ホストの 1ステップ平均 2.3 → 1.0 ミリ秒 に なりました。

## キャラを 作りなおすとき

```
python3 tools/meme-chars/make_chars.py
```

同じ たね（seed）からは いつも 同じ300体が できるので、セーブの id は ずっと 同じキャラを さします。
手作りの 60体は `tools/meme-chars/specials.py`、どうぶつと ものは `vocab.py`。

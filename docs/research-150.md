# 新しい150本のためのリサーチ（2026年9月）

いまの80本（1〜80）に加えて、81〜230の150本を作ります。
Roblox で人気のジャンルと、2025〜2026年に流行ったゲームを調べ、
**いまの80本とかぶらないもの**を10の分野から15本ずつ選びました。
本物のゲームの名前・キャラクター・ロゴは使わず、遊び方の「型」だけを参考にしたオリジナルです。

## わかったこと

- いちばん遊ばれているのはシミュレーター（集める→売る→強くなる）。次にアスレチック（オビー）とタイクーン。
- 2025〜2026年に伸びたのは「基地を守って盗む」タイクーン、庭を育てる放置系、協力ホラー、アニメ風の対戦、着せかえコンテスト、釣り。
- 友だちと遊ぶ定番は、役わけ推理、ロールプレイの街、ペットのお世話、パーティーのミニゲーム大会。
- 小さい子にも人気なのは、乗り物、どうぶつ、パズル（脱出）、スポーツ、お店屋さん。

## 共通のエンジン（lib/）

150本を同じ質で作るため、よく出てくる「型」を先に共通のスクリプトにしました。各ゲームはこれを読み込んで、自分のルールと地図を足します。

| ファイル | 中身 |
|---|---|
| `lib/rounds.absc` | ラウンドの進みかた（待つ → カウントダウン → 遊ぶ → 結果 → くり返し） |
| `lib/race.absc` | チェックポイント・周回・順位・タイム・ベスト記録（地面でも空中の輪でも） |
| `lib/ride.absc` | 乗り物の見た目（ボート・飛行機・ボードなどのブロックがついてくる）と、空を飛ぶ・水に浮く動き |
| `lib/ball.absc` | ボール（ける・投げる・打つ、はね返り、ゴールの判定） |
| `lib/waves.absc` | 敵の波・道・拠点・タワー（タワーディフェンスや防衛戦） |
| `lib/obby.absc` | アスレチックのステージとチェックポイント、落ちたら戻る |
| `lib/collect.absc` | 集めて売る（エリアにアイテムがわく・バッグ・売り場） |
| `lib/tycoon.absc` | 区画をもらって、買うほど建物が増えて、収入が入る |
| `lib/quiz.absc` | クイズ（問題・4択・時間・点数） |

# Ablox Games

[Ablox](https://github.com/prak59459-create/Ablox) の「ゲーム」タブが読むゲーム一覧です。
80本のゲームが入っています。どれも Ablox Studio で開いて、そのまま改造できます。

> The public game list for Ablox: 80 games, each a world plus `.absc` scripts.
> The app reads `index.json` straight from this repository.

## 遊び方

1. iPad の Ablox で **設定 → ゲーム一覧** を開く
2. リポジトリは `prak59459-create/AbloxGames`（最初から入っています）
3. ブランチは、このブランチを使うなら `claude/ablox-ipad-platform-8e8d8m`、`main` に入ったら `main`
4. 「ゲーム」タブで遊びたいゲームを選んでダウンロード → ホスト

Ablox Studio の「公開ゲームを開く」からも、同じ一覧のゲームをプロジェクトとして開けます。

## しくみ

```
index.json                      アプリが読む一覧
lib/kit.absc                    全ゲーム共通の道具（お金・ショップ・クエスト・レベル・実績・遊び方表示…）
games/<id>/world.ablox          マップ（ブロック）
games/<id>/main.absc            そのゲームのスクリプト
games/<id>/listing.json         一覧の1行分
tools/generator/                マップを作るプログラム（Swift）
tools/build.sh                  全部を作り直して、チェックして、自動で遊んで確かめる
```

- 各ゲームは `lib/kit.absc` と `games/<id>/main.absc` の2つの `.absc` を読み込みます
  （`index.json` の `scripts`）。スクリプトを GitHub で直せば、次にダウンロードしたときから反映されます。
- マップは `tools/generator/Maps*.swift` にコードで書いてあります。家・木・道・アリーナなどの
  部品を共有しているので、部品を直すと全部のマップに反映されます。

## 作り直しとテスト

```sh
git clone https://github.com/prak59459-create/Ablox ../Ablox
ABLOX=../Ablox tools/build.sh           # 全部（数分）
ABLOX=../Ablox tools/build.sh --only 12 # 1本だけ
ABLOX=../Ablox tools/build.sh --quick   # 自動プレイを短く
```

`build.sh` はアプリと同じ `AbloxCore` を一緒にコンパイルして、

1. 全マップを作って `world.ablox` を書く
2. 全スクリプトを文法チェック（Studio の「チェック」と同じ）
3. **ロボットのプレイヤー4人で150秒ずつ遊ぶ** — 画面のボタンを全部押し、テキストを入力し、
   反応するブロックに触れ、タップし、近くの相手を撃ち、チャットし、途中参加・途中退出もする。
   スクリプトのエラーが1つでも出たら失敗
4. `index.json` をアプリと同じ方法で読み直して、全部のリスティングが通るか確かめる

## オリジナルについて

ジャンルは人気の定番ゲームを参考にしていますが、名前・キャラクター・世界観はすべてこのリポジトリ用のオリジナルです。
実在のゲームやアニメ、会社の名前やキャラクターは使っていません。
